# Rectángulo

## Descripción

Cálculo de área y perímetro de un rectángulo.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- Variables numéricas
- Operaciones aritméticas
- Fórmulas geométricas
- Salida por consola

## Archivos principales

- `src/Main.java`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.

## Ubicación dentro del portfolio

Este proyecto forma parte del repositorio **Programación II — Portfolio Java**.
