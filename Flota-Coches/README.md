# Flota de coches

## Descripción

Modelo de vehículos, repostajes y cálculo de consumo medio.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- Herencia y clases relacionadas
- Modelado de entidades
- Cálculo de consumo
- Organización de varias clases

## Archivos principales

- `src/Coche.java`
- `src/Consumo.java`
- `src/Main.java`
- `src/Moto.java`
- `src/Repostaje.java`
- `src/Vehiculo.java`
- `TAD Consumo.docx`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.
