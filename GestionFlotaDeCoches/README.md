# Gestión de flota de coches

## Descripción

Aplicación de consola para gestionar una flota de coches con menú y archivos de datos.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- Menús por consola
- Gestión de colecciones
- Lectura/escritura de archivos
- Separación de responsabilidades

## Archivos principales

- `src/CalificacionAmbiental.java`
- `src/Coche.java`
- `src/GestorCoches.java`
- `src/Main.java`
- `informe.txt`
- `miscoches.che`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.
