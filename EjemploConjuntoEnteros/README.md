# Ejemplo conjunto de enteros

## Descripción

Implementación de un conjunto de enteros con operaciones como unión e intersección.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- Diseño de clases
- Arrays o estructuras internas
- Métodos de operación
- Unión e intersección de conjuntos

## Archivos principales

- `src/ConjuntoEnteros.java`
- `src/Main.java`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.
