# Gestión Bolsa 2.0

## Descripción

Aplicación de consola para gestionar una cartera de inversión, activos, operaciones y cuenta bancaria.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- POO con varias entidades
- Herencia o jerarquía de activos
- Operaciones de compra/venta
- Generación de informes
- Menú interactivo

## Archivos principales

- `src/Accion.java`
- `src/Activo.java`
- `src/Cartera.java`
- `src/Cuenta.java`
- `src/ETF.java`
- `src/FondoInversion.java`
- `src/Main.java`
- `src/Operacion.java`
- `src/TipoOperacion.java`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.
