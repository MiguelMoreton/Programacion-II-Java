# Polinomios

## Descripción

Representación y operaciones básicas con polinomios.

## Estado

Proyecto revisado para el portfolio de GitHub. Se mantiene como práctica académica independiente.

## Conceptos trabajados

- Clases auxiliares
- Representación de datos matemáticos
- Métodos de cálculo
- Pruebas desde `Main`

## Archivos principales

- `src/Main.java`
- `src/Polinomio.java`

## Ejecución

Desde esta carpeta:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

> Algunos proyectos solicitan datos por teclado; en ese caso hay que introducirlos cuando aparezca el menú o el mensaje en consola.
