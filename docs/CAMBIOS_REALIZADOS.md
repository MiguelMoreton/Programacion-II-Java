# Cambios realizados

Este documento resume los cambios aplicados para que el material se vea más claro y profesional en GitHub.

## Organización

- Se separó cada práctica en una carpeta independiente.
- Se mantuvo la carpeta `src/` como ubicación principal del código fuente.
- Se eliminaron archivos generados por el IDE o por compilaciones anteriores.
- Se quitó el script global de compilación para evitar la impresión de que todos los proyectos forman una única aplicación.

## Documentación

- Se creó un README principal con índice, descripción y forma de ejecución.
- Se añadió un README individual a cada proyecto.
- Se documentaron los conceptos trabajados en cada ejercicio.
- Se añadió un mapa del repositorio para facilitar la navegación.

## Revisión técnica

- Se verificó que los proyectos incluidos compilan de forma independiente.
- Se descartaron ejercicios incompletos o con errores de sintaxis.
- Se aplicaron pequeñas correcciones necesarias para que los proyectos incluidos funcionen correctamente.

## Objetivo del resultado

El repositorio queda preparado como portfolio académico: ordenado, navegable y fácil de revisar desde GitHub.
